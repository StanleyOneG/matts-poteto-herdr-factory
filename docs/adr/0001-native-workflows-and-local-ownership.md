# Use native workflows and checkout-local ownership

[Spec #1](https://github.com/StanleyOneG/matts-poteto-herdr-factory/issues/1) assigns engineering methodology to skills, meaningful tests and independent review, while Legion code controls launch, ownership, isolated writes, execution state and authorized effects. The approved redesign replaces repository-wide task coordination and custom skill/TDD proof protocols with one active Legatus per working checkout and ordinary native child workflows to reduce owned code and cost per accepted outcome. Users must partition work between independent Legati; unsupported recovery may preserve work and ask for a decision rather than guaranteeing autonomous completion.

This is a product boundary change, not a claim that native capability ceilings reproduce Legion's old final-execute wrappers. Existing records and resources remain preserved; no storage backend replacement follows from this decision.
